## 一、本章导语

为什么不能把模型名写死在代码里？本章讲逻辑模型与物理模型分层、Capability/TaskProfile 路由、效果成本稳定平衡、按租户的模型策略。

## 二、教学目标

建立逻辑/物理分层；实现按任务智能路由与 Fallback；掌握多租户模型权限/预算/区域治理。

## 四、核心概念拆解

| 概念 | 说明 |
|------|------|
| 逻辑模型 | 业务抽象，如'分析模型' |
| 物理模型 | 具体 API，如 luna |
| TaskProfile | 任务能力需求 |
| Fallback | 回退候选 |
| 租户策略 | 每租户模型白名单/预算 |

## 五、关键代码（可运行，指向 dataagent 模块）

```python
from dataagent.infra.gateway.llm_runtime import Router, ModelRegistry
from dataagent.contracts.model import ModelCapability
reg = ModelRegistry()
reg.register(ModelCapability(model='luna')); reg.register(ModelCapability(model='default'))
rt = Router(reg); rt.add_route('conclusion', ['default', 'luna'])
print(rt.decide('conclusion'))
```

运行方式：

```bash
cd dataagent && PYTHONPATH=src python -m pytest -k llm_runtime -v
```
