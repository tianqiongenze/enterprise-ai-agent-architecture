## 一、本章导语

模型调用成功≠任务成功。本章建立 LogicalCall/Attempt 执行模型，讲 Retry/Fallback/Timeout/Deadline、Structured Output/Schema Validation、流式最终提交。

## 二、教学目标

建立 LogicalCall/Attempt 生命周期；实现可靠重试与回退；用契约阻止无效结果进入下游；正确处理流式。

## 三、心智模型图

```mermaid
flowchart LR

  Spec --> Contract[契约 Contract]
  Contract --> Test[测试 TDD]
  Test --> Loop[受控执行 Loop]
  Loop --> Verify[独立验证 Verify]
  Verify --> Deliver[渐进交付]


## 四、核心概念拆解

| 机制 | 解决的问题 |
|------|-----------|
| Retry | 瞬时失败 |
| Fallback | 模型不可用 |
| Timeout/Deadline | 卡死 |
| Schema Validation | 无效输出 |
| Stream+Commit | 中间结果干扰 |
