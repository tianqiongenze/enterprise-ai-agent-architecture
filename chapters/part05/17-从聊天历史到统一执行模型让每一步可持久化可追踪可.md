## 一、本章导语

让 Agent 的状态脱离聊天记录。本章讲 Run/Step/Attempt 统一 Runtime 语言、Event 与 Checkpoint 保存过程、Run State Machine 生命周期、Run Timeline 解释每一步。

## 二、教学目标

建立统一执行模型；用 Event/Checkpoint 实现崩溃恢复与追踪；用 Run Timeline 支撑运维审计。

## 四、核心概念拆解

| 对象 | 含义 |
|------|------|
| Run | 一次任务全生命周期 |
| Step | 演进中的一步 |
| Event | 不可变过程事件 |
| Checkpoint | 可恢复快照 |
| Timeline | 可解释轨迹 |

## 五、关键代码（可运行，指向 dataagent 模块）

```python
from dataagent.contracts.runtime import Run, EventType
r = Run(task_type='analysis')
st = r.add_step('plan'); r.add_event(EventType.STEP_STARTED, step_id=st.step_id)
cp = r.to_checkpoint(); r2 = Run(); r2.restore(cp)
print('Resume 恢复状态:', r2.status)
```

运行方式：

```bash
cd dataagent && PYTHONPATH=src python -m pytest -k contracts -v
```
