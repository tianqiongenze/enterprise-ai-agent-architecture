## 三、三条"已知边界"闭合记录（联网调研定案 → 实现 → 实测）

### 3.1 异步任务不落库 → 真实队列消费落库
- **调研**：[Pulsar DLQ/NACK 官方语义](https://docs.spring.io)（Shared 订阅 + negative_acknowledge + DeadLetterPolicy(max_redeliver_count→DLQ)，任务需幂等）
- **实现**：`services/shared/queue.py`（Pulsar 优先/Redis List 兜底，NACK 重试，超限落 DLQ）+ `services/worker/main.py`（消费→执行→CRDB `dataagent_tasks`/`dataagent_runs` 落库→Redis 镜像）+ K8S Worker Deployment
- **LAN 实测**：入队 201 → Worker 消费 → `waiting_approval` → 审批 → `succeeded`；终态任务查询 200 全链路 ✓
- **踩坑记录**：镜像缺 pyjwt/redis 包两次 CrashLoop；worker1 节点 stale image cache（IfNotPresent）→ 0.3.0 新 tag + Always 修复

### 3.2 无鉴权 → JWT + RBAC
- **调研**：[Litestar JWT Security Backends](https://docs.litestar.dev/main/usage/security/jwt.html)（JWTAuth + retrieve_user_handler(token, connection)、密钥走 env、exclude 公共路由）
- **实现**：`services/api/auth.py`（pbkdf2 口令、CRDB `dataagent_users` + Redis 镜像、admin/approver/analyst/viewer 种子）+ 全业务/管理路由 JWT 保护（401/403 实测）
- **LAN 实测**：未登录 401 / 错误密码 401 / analyst 访问 tenants 403 / admin 全通 ✓

### 3.3 审批自动通过 → 真实审批人接入（ApprovalPort HITL）
- **调研**：HITL 最佳实践 = **风险分级的 interrupt/resume 检查点** + 完整审计（审批人身份/时间戳/完整动作上下文防 UI 截断攻击）
- **实现**：内核新增 `ApprovalPendingError`（human_gate 处 interrupt）+ `execute(pre_approved=...)`（resume）；审批单落 `dataagent_approvals`；API `POST /v1/admin/approvals/{id}/resolve`（写 decided_by/decided_at 审计）→ 后台自动恢复工作流；控制台"审批中心"展示完整上下文
- **LAN 实测**：批准 → task `succeeded`；拒绝 → task `canceled`；重复决议 404 ✓
- **合同落地**：`contracts.runtime.ApprovalPort` 的真实实现即 ApprovalStore（CRDB+Redis），演示 InMemoryApprovalPort 降级为 `DATAAGENT_APPROVAL_MODE=auto`
