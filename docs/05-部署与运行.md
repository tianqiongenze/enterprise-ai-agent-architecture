# 部署与运行

## 1. 本地离线运行（推荐，零依赖外部 API）

```bash
cd dataagent
pip install -r requirements.txt        # pytest, pydantic
PYTHONPATH=src python -m pytest -v     # 全部测试
PYTHONPATH=src python -m dataagent "华东区本月 GMV 下滑原因诊断"
python ../scripts/demo.py              # 端到端演示
```

> 项目内置 `FakeLlmClient`，无需任何 API Key。真实模型只需替换 `adapters/llm` 一个适配器。

## 2. Docker 部署（编译为可运行镜像）

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY dataagent/ ./dataagent/
COPY scripts/ ./scripts/
RUN pip install ./dataagent pytest
ENTRYPOINT ["python", "-m", "dataagent"]
```

```bash
docker build -t dataagent:latest .
# 以 CLI 方式运行容器内的 DataAgent
docker run --rm dataagent:latest "华东区 GMV 下滑诊断"
```

## 3. 演进式部署（第三篇第1课路径）

| 里程碑 | 部署形态 | 说明 |
|--------|----------|------|
| M0 | 模块化单体（进程内） | 当前仓库即此形态，可离线跑通全部能力 |
| M1 | 拆 LLM Runtime 为服务/网关 | `ReliableExecutor` 已可独立部署 |
| M2 | Agent API + Scheduler + Queue + Worker | `contracts.runtime.TaskQueue/Worker` 端口，替换为真实队列 |
| M3 | 多租户 + 云端 Sandbox + 分布式 | 5（Sandbox 端口、租户隔离已就位）|
| M4 | 生产治理：Trace/Eval/安全/发布 | `infra/metrics`、`infra/security`、CI 门禁就位 |

> 关键设计：所有基础设施通过 `Protocol` 端口抽象，演进即"换实现不换接口"，
> 保证从 M0 到 M4 的每一步都最小代价、可回滚。

## 4. CI / 回归门禁（GitHub Actions）

`.github/workflows/ci.yml`：push/PR 触发 → 安装 → `pytest` → 端到端 CLI 冒烟，
作为 `Regression Gate`（第九篇第5课）的落地，拦截"平均分提升但关键能力退化"。

## 5. 常见问题

- **导入失败**：请在 `dataagent/` 下设置 `PYTHONPATH=src` 或用 `pip install -e .`。
- **想用真实模型**：实现 `contracts.model.LlmClient` 协议并替换 `DataAgentContainer` 的 `client`。
- **分布式/审批接真实系统**：实现 `TaskQueue` / `ApprovalPort` 端口。
