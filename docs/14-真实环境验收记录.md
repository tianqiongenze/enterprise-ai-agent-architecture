## 二、Redis 真实联调（GAP-14 收口）

**部署**：自建 `dataagent-redis`（Deployment+Service，私有仓库 redis:7-alpine，无盘租约态）→ `deploy/real-env/redis-standalone.yaml`。

**六步租约序列**（worker pod 内执行，真实 `dataagent-redis.dataagent-prod.svc:6379`，lease_s=2.0 真实 TTL）：

```text
1) acquire: worker-probe gen 1
2) 冲突拒绝: OK
3) 租约期内接管拒绝: OK
4) TTL 过后接管: True | generation: 2
5) release(new owner): True
6) 重复 release: False
REAL REDIS LEASE SEQUENCE (6/6): ALL OK
```

**真机取证发现的协议缺陷（已修复）**：Lua `return false` 经 redis-py（decode_responses=True）返回 **None** 而非 b"false"——初版 `_run` 未处理 None 导致冲突/接管语义全歪。同批"pod 内文件未同步"造成假绿，被"清键重跑+逐项取证"揭穿。两课登记为 GAP-27（fake 必须对齐真实行为；探针脚本必须随代码同步分发）。
