一、课程定位​

这是一门面向已经具备大模型应用和基础 Agent 开发经验的工程师，帮助其从“能够实现一个 Agent
Demo 或业务项目”，升级为“能够设计、评审、建设和持续演进企业级 Agent 系统”的架构进阶课
程。​
课程不以重复讲解 LLM API、Prompt Engineering、基础 Tool Calling、基础 RAG 或某个 Agent 框架
的使用为主要目标，而是聚焦企业级 Agent 工程中真正决定系统可落地、可扩展、可维护的架构设计
与工程治理问题，帮助学员完成从 Agent Developer 到 Agent Architect 的关键能力跃迁。​
课程不仅关注如何开发企业级 Agent，更关注为什么这样设计、为什么这样组织团队、为什么这样与
AI 协作。它希望帮助学员建立 AI 时代真正具备长期竞争力的工程能力，而不是停留在某一种框架或技
术栈的使用层面。​
课程同时将架构选型与评测验证作为一条贯穿主线：每个阶段不仅讲“如何实现”，还要求学员比较
候选方案、识别适用条件和关键取舍，并通过 Baseline、Badcase、Benchmark 与 ADR 为架构决
策提供证据。课程将结合 DSH（DeepSeek Harness）等前沿开源 Harness 的源码设计，以及
Graph Engineering 对复杂执行拓扑的建模方法，帮助学员理解最新实践背后的稳定工程对象，而不
是把课程绑定在某个框架或版本上。​
课程将围绕企业级 Agent 系统设计中的核心架构问题展开：​
• 如何建立对于 LLM、AI Agent 和 AI Native 的底层认知，理解 Agent 的本质、边界和未来演进方

向，形成属于 AI 时代的软件工程思维；​
• 如何理解 AI Coding 带来的研发范式变革，建立人与 AI 高效协作的方法论，掌握 AI Coding 的理
念、技巧、Workflow 与 Infra，使 AI 成为工程能力的放大器，而不是简单的代码生成工具；​
• 如何理解大厂 Agent 架构师真正需要具备的能力模型，建立从 Demo 开发到企业级系统设计的完整
成长路径；​

• 如何掌握 PE、CE、HE、LE、GE 等 Agent 调优技术体系，理解各种 Agent Engineering 技术背后

的设计思想，而不是停留在经验式 Prompt 调整；​
• 如何判断一个业务问题是否真正适合 Agent，并根据业务特点选择最恰当的 Agent 架构，发挥
Autonomous Agent 和 Workflow Agent 各自的优点；​
• 如何完成企业级 Agent Runtime 的架构设计，将单机 Agent Loop 演进为支持长任务、状态持久
化、故障恢复、水平扩展、多 Agent 协同和分布式执行的运行时系统；​
• 如何建立企业级 Agent 的系统抽象能力，将 Model、Context、Knowledge、Tool、Skill、
Memory 等能力从业务逻辑中解耦，形成可复用、可治理、可持续演进的基础能力体系；​
• 如何建立企业级 Agent 的可观测、可回放、可评测和可持续演进体系，通过 Trace、Replay、
Eval、Regression Gate 等工程机制持续提升系统质量，而不是依赖 Prompt 调试和经验排查。​
课程最终训练的是企业级 Agent 的：​
• 架构判断能力；​

• 运行时设计能力；​
• 系统抽象能力；​
• 工程治理能力；​

• 可靠性设计能力；​

• 可观测与诊断能力；​
• 生产演进能力；​

• 架构交付与评审能力；​

三、贯穿项目设计​
课程提供一个统一的 B 端贯穿项目。所有学员围绕同一业务场景持续迭代，从模块化单体逐步演进为
支持多租户、长任务、云端 Sandbox、微服务部署和持续评测的企业级 Agent 系统。项目统一承载课
程中的 LLM Runtime、分布式 Agent Runtime、Context、Tool、Memory 与 EvalOps 能力。​

贯穿项目：企业级多租户零售经营分析与决策 DataAgent​
该项目面向品牌商家和零售企业，为多个企业租户提供经营数据分析、异常诊断、决策建议和受控业
务执行能力。项目不止实现自然语言查数，而是让 Agent 能够围绕真实经营问题，自主完成分析规
划、数据查询、Python 分析、证据验证和行动闭环。​

典型任务​
企业用户提交一个跨数据源与业务系统的经营问题，例如：​
• 查询订单、商品、库存、会员、广告和售后数据；​
• 理解企业指标口径，自主生成多步骤分析计划；​
• 通过 SQL 与云端 Python Sandbox 完成数据查询、统计分析和图表生成；​
• 诊断 GMV、毛利、转化率、退款率或库存等指标异常，并形成证据链；​
• 生成补货、营销、人群运营或预算调整等行动建议；​
• 对创建工单、调整预算和写入业务系统等操作发起人工审批；​
• 周期性生成经营报告、监测异常，并持续跟踪行动效果；​
• 由管理员配置租户级数据源、指标、模型、工具、预算和权限。​

需要解决的架构问题​

• 多租户、组织角色与数据权限；​
• 数据源凭据和查询结果隔离；​

• 指标、维度、业务术语和数据血缘治理；​

• 行列级权限、只读 Query Gateway 与 SQL 安全；​

• Workflow 与 Autonomous Analysis Loop 混合编排；​
• SQL 执行与 Python Sandbox 隔离；​
• 数据新鲜度、质量验证与证据追踪；​

• 有副作用工具的风险分级与 Human Approval；​
• 经营结论、执行轨迹、审计日志与回归门禁。​

共用平台底座​

企业级多租户 DataAgent 共用平台底座架构图​

3. 拆出 Agent API、Scheduler、Worker 和 Sandbox；​
